## 3. リリース前 手動QAチェックリスト(実機: iOS/Android各1台)

**A. コア体験(DEMOモード)**
- [ ] 初回起動→初納品まで詰まりなく完了、演出のタップスキップが効く
- [ ] クエスト中に強制終了→再起動で「おかえり！つづきから」
- [ ] 文字サイズをOS設定で1.3倍にしてもレイアウト崩れなし(Phase 8 §4)
- [ ] 「視差効果を減らす」ONで演出がフェードに縮退(Phase 8 §8)

**B. 本番モード(USE_FIREBASE=true・ステージング)**
- [ ] 匿名認証→initUser→ホーム表示(todayOffersフォールバック含む)
- [ ] 画像選択→アップロード→添削30秒以内→6軸付き結果
- [ ] 機内モードで提出→「荷物が届かなかったみたい」→再試行で成功
- [ ] 添削の日次上限到達→「今日はたくさん頑張ったね」系の文言(生エラー非表示)
- [ ] 納品直後に通信断→アプリ再起動→報酬が二重付与されていない(冪等の実機確認)
- [ ] 不適切画像(無関係な写真)提出→優しい差し戻し

**C. セキュリティ(ステージング)**
- [ ] REST APIから自分のxpをPATCH→PERMISSION_DENIED
- [ ] review_promptsのGET→PERMISSION_DENIED

cd app && flutter analyze && flutter test

cd ../content && npm run validate

# エミュレータ系
firebase emulators:exec --only firestore --project design-kingdom-test '
  (cd firebase/tests && npm test) && (cd functions && npm run test:integration)'

cd functions && ANTHROPIC_API_KEY=... npm run eval -- --prompt rp_pop_basic
